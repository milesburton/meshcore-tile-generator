# Meshcore Tile Generator

This project is a TypeScript-based tile generator powered by Bun.

## Getting Started

1. Install dependencies:
   ```bash
   bun install
   ```

2. Run the generator:
   ```bash
   bun run index.ts
   ```

## Features

- Tile generation for Meshcore
- Fast execution with Bun
